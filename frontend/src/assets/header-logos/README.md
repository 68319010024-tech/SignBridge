# โลโก้บนแถบหัวเว็บ /ai2/

วางไฟล์รูปโลโก้ไว้ในโฟลเดอร์นี้ (รองรับ .png .jpg .jpeg .svg .webp) แล้ว build/deploy ใหม่
โลโก้จะขึ้นแทนไอคอนรูปมือบนแถบหัวเว็บ เรียงจากซ้ายไปขวาตามชื่อไฟล์ จึงควรตั้งชื่อนำด้วยเลข เช่น

- 1-logo.png
- 2-logo.png

ใส่กี่รูปก็ขึ้นเท่านั้น (ตอนนี้ใช้ 2 โลโก้)

แต่ละโลโก้แสดงในวงกลมพื้นขาว ขนาด 44px (มือถือ 36px) จึงควรใช้รูปทรงจัตุรัส พื้นหลังโปร่งใส
ถ้าโฟลเดอร์นี้ไม่มีรูปเลย จะกลับไปใช้ไอคอนรูปมือตามเดิม ส่วนเว็บ /ai/ ไม่แสดงโลโก้เหล่านี้
