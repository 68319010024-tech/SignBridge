ขั้นตอนย้าย SignBridge ไปรันบนโน้ตบุ๊คเครื่องใหม่ (เช่น พกไปแข่งที่กรุงเทพ)
ทำครั้งเดียวให้เสร็จ "ก่อน" วันแข่ง อย่าเพิ่งมาลองหน้างานครั้งแรก

============================================================
A. ติดตั้งของพื้นฐานบนเครื่องใหม่ก่อน
============================================================
1. Python 3.11.x (ที่ทดสอบไว้คือ 3.11.9)
2. Docker Desktop
3. Node.js (เวอร์ชัน LTS ล่าสุด ไม่ต้องตรงเป๊ะ)

============================================================
B. ย้ายไฟล์
============================================================
4. ก็อปโฟลเดอร์ SignBridge ทั้งโฟลเดอร์ไปเครื่องใหม่ (USB / external drive)
   - ต้องมี ai-engine/models/*.h5 และ ai-engine/dataset ติดไปด้วย
   - venv กับ node_modules ก็อปติดไปก็ไม่เป็นไร แต่ "ห้ามใช้ของเดิม"
     เพราะผูก path ของเครื่องเก่าไว้ รันบนเครื่องใหม่มีโอกาสพัง
     ให้สร้างใหม่ตามขั้นตอน C แทน

============================================================
C. ตั้งค่าบนเครื่องใหม่
============================================================
5. สร้าง Python venv ใหม่ + ลง dependency จาก requirements.txt ที่ pin ไว้แล้ว
   cd ai-engine
   python -m venv venv
   venv\Scripts\pip install -r requirements.txt

6. ลง frontend dependency ใหม่
   cd frontend
   npm install

============================================================
D. รันและทดสอบจริง (ทำก่อนวันแข่ง ไม่ใช่หน้างาน)
============================================================
7. รัน frontend
   docker compose -f docker/docker-compose.yml up -d --build
   แล้วเปิด http://localhost:8080

8. รัน ai-engine (จากโฟลเดอร์ ai-engine/)
   venv\Scripts\python.exe src\server.py

9. ทดสอบเซ็นภาษามือจริงหน้ากล้องเครื่องใหม่
   - โมเดลทำนายคำได้ปกติ
   - เซ็นหลายคำติดกันแล้วต่อเป็นประโยคได้ (ต้องเซ็นแต่ละคำห่างกันไม่เกิน 5 วิ)
   - กล้องขอ permission ผ่าน (ใช้ผ่านได้เพราะรันบน localhost)

============================================================
E. เมื่อได้ domain/server จากครูแล้ว (ทำทีหลัง แยกจากขั้นตอนย้ายเครื่อง)
============================================================
10. แก้ WS_URL จาก ws://127.0.0.1:8000 เป็นโดเมนจริง ในไฟล์:
    - frontend/src/pages/StudentDashboard.tsx
    - frontend/src/pages/GamePage.tsx
    (ต้องตั้ง reverse proxy + HTTPS/WSS บน server ฝั่งครูด้วย ไม่ใช่แก้ฝั่งเดียวจบ)

หมายเหตุ: ไฟล์นี้เก็บเป็น checklist อ้างอิงเฉยๆ ถ้าขั้นตอนจริงเปลี่ยนไป
ให้แก้ไฟล์นี้ตามด้วย จะได้ใช้อ้างอิงได้ถูกต้องเสมอ
