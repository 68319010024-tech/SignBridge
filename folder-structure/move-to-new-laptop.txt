ขั้นตอนย้าย SignBridge ไปรันบนโน้ตบุ๊คเครื่องใหม่ (เช่น พกไปแข่งที่กรุงเทพ)
ทำครั้งเดียวให้เสร็จ "ก่อน" วันแข่ง อย่าเพิ่งมาลองหน้างานครั้งแรก

(อัปเดตล่าสุด: ตอนนี้มี server จริงแล้วที่ http://webapp.htc.ac.th/ai/ และ
WS_URL ไม่ต้องแก้มือแล้ว เพราะ frontend เลือกปลายทางให้เองอัตโนมัติ
ดูรายละเอียดที่ส่วน E ด้านล่าง)

============================================================
A. ติดตั้งของพื้นฐานบนเครื่องใหม่ก่อน
============================================================
1. Python 3.11.x (ที่ทดสอบไว้คือ 3.11.9)
2. Docker Desktop
3. Node.js (เวอร์ชัน LTS ล่าสุด ไม่ต้องตรงเป๊ะ)
4. Git

============================================================
B. เอาไฟล์โปรเจกต์มาลงเครื่องใหม่
============================================================
ตอนนี้โปรเจกต์มี GitHub repo แล้ว (origin: github.com/68319010024-tech/SignBridge)
ใช้วิธี git clone แทนการก็อปทั้งโฟลเดอร์ผ่าน USB ได้เลย ง่ายกว่าและไม่ต้องพกไดรฟ์:

   git clone https://github.com/68319010024-tech/SignBridge.git
   cd SignBridge

หมายเหตุ: โฟลเดอร์ ai-engine/dataset (วิดีโอ/ข้อมูลดิบสำหรับเทรนโมเดลใหม่ ~4.7GB)
ไม่ได้อยู่ใน git (ใหญ่เกินไป) ถ้าจะไปแข่งแค่โชว์เดโม "ไม่จำเป็นต้องมี" เพราะ
โมเดลที่เทรนไว้แล้ว (ai-engine/models/*.h5) อยู่ใน git ครบอยู่แล้ว ใช้เดโมได้เลย
ต้องมี dataset นี้ก็ต่อเมื่อจะเทรนโมเดลใหม่หน้างานเท่านั้น (ถ้าต้องการ ให้ก็อปแยก
มาทาง USB เพิ่มเอง)

============================================================
C. ตั้งค่าบนเครื่องใหม่
============================================================
5. สร้าง Python venv ใหม่ + ลง dependency (requirements.txt ตัวนี้ pin ไว้สำหรับ
   Windows โดยเฉพาะ ใช้กับเครื่อง Windows ที่จะพกไปแข่งได้ตรงๆ):
   cd ai-engine
   python -m venv venv
   venv\Scripts\pip install -r requirements.txt

6. ลง frontend dependency ใหม่:
   cd frontend
   npm install

============================================================
D. รันและทดสอบจริงแบบ local (ทำก่อนวันแข่ง ไม่ใช่หน้างาน)
============================================================
ใช้โหมดนี้ตอนเดโมสด ไม่ต้องพึ่งอินเทอร์เน็ต/โดเมนเลย เชื่อถือได้กว่าเน็ตหน้างาน

7. รัน frontend:
   docker compose -f docker/docker-compose.yml up -d --build
   แล้วเปิด http://localhost:8080

8. รัน ai-engine (จากโฟลเดอร์ ai-engine/):
   venv\Scripts\python.exe src\server.py

9. ทดสอบเซ็นภาษามือจริงหน้ากล้องเครื่องใหม่:
   - โมเดลทำนายคำได้ปกติ
   - เซ็นหลายคำติดกันแล้วต่อเป็นประโยคได้ (ต้องเซ็นแต่ละคำห่างกันไม่เกิน 5 วิ)
   - กล้องขอ permission ผ่าน (ใช้ผ่านได้เพราะรันบน localhost)

============================================================
E. เรื่อง server จริง/โดเมน (webapp.htc.ac.th/ai/) — ไม่ต้องทำอะไรเพิ่มแล้ว
============================================================
- ตอนนี้ deploy ขึ้น server ของโรงเรียนแล้วจริง เข้าดูได้ที่
  http://webapp.htc.ac.th/ai/ (ใช้ Portainer + Nginx Proxy Manager ที่มีอยู่แล้ว
  รายละเอียดวิธี deploy/ตั้งค่า NPM ดูใน docker/docker-compose.deploy.yml)
- WS_URL "ไม่ต้องแก้ไฟล์เองแล้ว" — frontend/src/services/wsConfig.ts เลือกปลายทาง
  ให้อัตโนมัติจาก URL ที่เปิดเว็บอยู่: เปิดที่ localhost ใช้ ws://127.0.0.1:8000,
  เปิดผ่านโดเมนใช้ wss://webapp.htc.ac.th/ai/ws/ ให้เอง ไม่ต้องยุ่งอะไร
- ถ้าแก้โค้ดแล้ว push ขึ้น GitHub ใหม่ "เว็บจริงจะยังไม่อัปเดตให้อัตโนมัติ" ต้องเข้าไป
  สั่ง update stack ใน Portainer (environment "rov2") เองอีกที ถึงจะ build/deploy
  โค้ดใหม่ขึ้นเว็บจริง

หมายเหตุ: ไฟล์นี้เก็บเป็น checklist อ้างอิงเฉยๆ ถ้าขั้นตอนจริงเปลี่ยนไป
ให้แก้ไฟล์นี้ตามด้วย จะได้ใช้อ้างอิงได้ถูกต้องเสมอ
